# gumee desktop downloads

Download the latest gumee installers from [Releases](https://github.com/marvj69/gumee-releases/releases/latest).

- **Mac:** Apple Silicon DMG or ZIP. Drag gumee into Applications.
- **Windows:** x64 installer for Windows 10 or 11.
- **Linux:** x86_64 AppImage.

These installers are unsigned; the Mac builds are not notarized.

Version 0.2.1 reads text from JPEG, PNG, WebP, GIF, BMP and TIFF images and scanned PDF pages with bundled local English OCR. No separate OCR key or language download is needed. Recognized text is sent to your selected OpenRouter model as document context. OCR may misread handwriting, names or numbers; it does not interpret photographs or diagrams. HEIC images need conversion to JPEG or PNG. Long PDFs can be read in batches of up to 20 scanned pages per call.

See the [installation guide](INSTALL.md), [release notes](RELEASE_NOTES.md), and [license](LICENSE). Verify downloaded files against the release's SHA256SUMS.txt. This repository distributes the installers.
